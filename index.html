Kebijakan Privasi

Mafia Sawit · terakhir diperbarui 20 Oktober 2026
Ringkasnya: Mafia Sawit tidak mengumpulkan data pribadi apa pun. Game ini berjalan sepenuhnya offline dan tidak memiliki akses internet.

1. Data yang dikumpulkan

Mafia Sawit tidak mengumpulkan, mengirim, atau membagikan data pribadi maupun data teknis pengguna. Tidak ada akun, tidak ada pendaftaran, tidak ada analitik, dan tidak ada pelacakan.

2. Izin aplikasi

Aplikasi tidak meminta izin apa pun yang berkaitan dengan data pengguna. Secara teknis aplikasi tidak meminta izin INTERNET, sehingga aplikasi secara desain tidak dapat mengirim data ke mana pun.

3. Data yang disimpan di perangkat

Progres permainan (level, pangkat, dan pengaturan) disimpan secara lokal di perangkat Anda. Data ini tidak pernah meninggalkan perangkat dan akan terhapus bila Anda menghapus aplikasi atau menekan “Reset progres” di menu utama.

4. Iklan dan pembelian

Versi saat ini tidak menampilkan iklan dan tidak memiliki pembelian dalam aplikasi. Bila di versi mendatang iklan ditambahkan, kebijakan ini akan diperbarui sebelum versi tersebut dirilis, dan pengaturan “Berisi iklan” di Play Store akan disesuaikan.

5. Anak-anak

Aplikasi tidak mengumpulkan data dari siapa pun, termasuk anak di bawah 13 tahun.

6. Perubahan kebijakan

Perubahan kebijakan akan dipublikasikan di halaman ini beserta tanggal pembaruannya.

7. Kontak

Pertanyaan mengenai privasi dapat dikirim ke dn12.dev@gmail.com.
